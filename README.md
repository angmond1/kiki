# KIST 행정 자동화 skill 패키지

KIST 구성원이 Claude Code로 **반복적인 행정 업무**를 자동화하는 skill 모음.
대부분 **본인 브라우저 로그인만으로 동작**(별도 토큰·비번 없음). 일부 기능(지급신청 업로드)만 개인 Dooray 토큰이 필요하며 설치 때 안내한다.

## 구성 skill
| skill | 용도 |
|-------|------|
| **kk-mail** | Dooray 메일 — 스팸 신고 · 폴더 분류 · 자연어 자동분류 규칙 |
| **kk-pay** | 연구비 지급신청 — 증빙 비목 분류 · 파일명 변환 · 행정원 폴더 업로드(RPA 기안) |
| **kk-inspect** | 물품 소액검수 신청 — 증빙 파악 · 자산 판정 · 검수창 자동 입력 |
| **kk-budget** | 과제 예산 조회 — 예실대비표 수집 · 엑셀 리포트 (조회 전용) |
| **kk-dining** | 회의비 처리 — 회의록 관리 · 지급신청서 자동 작성·상신 |

---

## kk-mail — 메일 관리
- 광고성·predatory 메일을 자동 식별해 **스팸 신고**.
- 결재알림·과제·UST·기관뉴스·학회 등 **권장 폴더로 분류**(설치 때 항목별로 물어봄).
- *"앞으로 nature.com 메일은 저널 폴더로"* 처럼 **자연어 한마디로 자동분류 규칙 생성**(폴더 없으면 자동 생성).

## kk-pay — 지급신청
- 영수증·세금계산서·회의비 증빙을 **비목별로 분류**하고 규칙 파일명으로 변환.
- 카드 **승인번호·과제·금액을 자동 조회**(화면 좌표 없이 동작).
- 담당 행정원 Dooray 폴더에 **업로드하면 RPA가 자동 기안**.
- 비목이 애매하면 규정을 찾아 제안하고 **최종 확정은 본인**. 모든 업로드는 확인 후.

## kk-inspect — 소액검수
- 거래명세서·세금계산서·카드영수증에서 **품목·금액·수량 파악**.
- **자산/비자산 자동 판정**(대부분 비자산으로 진행, 자산일 때만 확인).
- 외화 결제는 **카드영수증조회의 확정 원화** 사용.
- 검수창에 **자동 입력** → 최종 **첨부·신청 버튼은 본인**이 누름.

## kk-budget — 예산 조회
- 과제별 **예산(예실대비표)을 자동 수집**.
- 카테고리별 **총액·집행·잔액 + 직접비 소계**를 로컬 엑셀 + 채팅 표로 출력.
- 공동과제는 **본인 지분만 집계**(선택).
- **조회·로컬 저장 전용** — 포털에 아무것도 제출/변경하지 않음.

## kk-dining — 회의비 처리
- 카드 회의비를 **자동 추출**하고 사전결재와 매칭.
- 인원·회의시간·참석자·회의내용을 **자동 구성**, 회의록을 엑셀로 관리.
- 회의비 **지급신청서를 자동 작성·임시저장·결재상신**(최종 상신은 본인 확인).
- 회의록 hwp 동봉은 선택.
