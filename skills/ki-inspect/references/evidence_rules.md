# 증빙 파악 규칙 (세금계산서 / 거래명세서 / 카드영수증)

## 입력
폴더(기본 `<config.inspect_folder>`)의 증빙 파일을 읽는다:
- 세금계산서 PDF, 거래명세서 PDF, 카드영수증/명세 PDF·이미지, 물품 사진 JPG.
- 한 거래(한 검수건)는 보통 세금계산서/영수증 + 거래명세서 + 물품사진 묶음.

## 세금계산서 vs 카드결제 판별
- **세금계산서**(전자세금계산서·국세청 승인번호) → 세금계산서 건. 취득가 = **합계금액(공급가액+VAT)**.
- **카드영수증/카드명세**(카드사·승인번호·일시불 등) → 카드결제 건. 취득가 = **fam_0711 USEAMT 확정 원화**(`fam0711_fx.md`). 외화면 특히 필수.

## 필드 추출 규칙

**품명 (PROD_NM)**
- 품목 1개: 품목명 그대로 (규격이 별도면 품명 뒤 붙임).
- 품목 2개 이상: `"<첫품목명> <규격> <수량>ea 외 N종"` (N = 품목수 - 1).
- **슬래시·괄호 제거**: `4/pk`→`4 pk`, `(X)`→ 내용만, `14/20`→`14-20`.

**모델 (MDL_NM)**
- 거래명세서 물품코드가 있으면 그 코드(첫 품목). 없으면 품목명/제품 모델명.

**수량 (QTY) + 단위 (UNIT)**
- 품목 1개: 그 수량 + 품목 단위(ea/set 등, `code_tables.md`).
- 품목 2개 이상: QTY = **종 수**, UNIT = `0154`(종).
- 무형(SW 등): QTY=1, UNIT=`0155`(기타).

**취득일 (OBT_DT)**: 세금계산서 작성일(또는 카드 사용일) → YYYYMMDD.

**취득가 (OBT_AMT)**: 세금계산서 합계금액(VAT포함) · 카드결제는 fam_0711 USEAMT.

## 파일 전처리 (업로드 전)
- `png/jpeg/bmp/tiff` → `jpg` 변환 (두레이 RPA 업로드 불가 형식). pdf는 그대로. → `scripts/convert_evidence.py`
- 무의미한 무작위 숫자 파일명 → `{YYMMDD} {원화금액} {거래처 내용} 카드영수증.jpg` 식 개명, 원본 휴지통. → `scripts/rename_evidence.py`

## 첨부 대상 (검수신청)
세금계산서/영수증 PDF + 거래명세서 PDF + 물품 사진 JPG(품목별). 카드 무형 건은 카드명세 jpg + 영수증 pdf. (첨부·신청은 사용자가 직접)
