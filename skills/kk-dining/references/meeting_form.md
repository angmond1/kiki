## (옵션) hwp 별지1호 양식 = 회의비 사용내역서(회의록), 7x7 표 1개
`pyhwpx.get_into_nth_table(0)` 진입 후 `TableRightCell()` 순회. **값 셀 인덱스**:

| 셀 | 값(data 키) | 셀 | 값(data 키) |
|:--:|------|:--:|------|
| 1 | account 계정번호 | 13 | time 회의시간 |
| 3 | pi_ins 연구책임자(+" (인)") | 15 | content 회의내용 |
| 5 | amount 금액(예 `104,200 원`) | 18 | ext_cnt 외부인원 |
| 7 | place 회의장소 | 19 | ext_mem 외부명단 `(소속) 성명` |
| 9 | date 회의일자(예 `2026. 5. 21.`) | 21 | int_cnt 내부인원 |
| 11 | purpose 회의목적(=회의록 제목) | 22 | int_mem 내부명단 `성명, 성명` |

라벨 셀(0,2,4,6,8,10,12,14,16,17,20)은 **건드리지 않음** → 원본 양식 100% 보존.
- 셀 채우기: `TableCellBlock()` → **`Erase()`**(⚠️ Delete 는 셀 안 지워짐) → `insert_text()`. 여러 줄은 `hwp.hwp.HAction.Run('BreakPara')`.

## 인원 산정 (2026-06-05 정정)
- **필요 인원 = ⌈금액(식대+음료 합산) ÷ 50,000⌉ + 1명** (규정 **1인 5만원 한도 = 식대+음료(액체 다과) 합산** + 여유 1명) — **kk-dining 표준 산정식**.
- ⭐ **같은날 식당+카페 = 합산 금액**으로 산정 (옛 "카페 음료 잔수=인원" 폐기 — 식당+카페 따로 보지 않고 합산). 예: 식당 70,000 + 카페 28,300 → 합산 98,300 → ⌈1.966⌉+1 = 3명.
- 카페 영수증 음료 수는 증빙 일치 참고만 (인원 산정 기준 아님).
- 내부/외부 배분은 사용자 지정. 외부=`(소속) 성명`, 내부=성명만.

## 회의시간 융통성 (2026-06-05 신규)
- **회의 종료시간 = 카드승인시간(`ds_datagrid1.USETIME`) 참고 융통성 설정**. 결제는 회의 직후 → **종료 ≤ 결제**.
- 예: USETIME 14:38 → 회의 13:00~**14:30** (결제 직전 정각/반정각으로 자연스럽게).
- 30분/시간 단위 반올림. 회의 시작은 1시간/1시간 30분 전 일반적.

## 회의비 판별 + 증빙(영수증) — 재무팀 매뉴얼(2026.06) 기준
- 회의비 = **음식점·카페 카드결제**. 같은 날 식사+카페 = 1건(금액 합산).
- 기본은 **카드매출전표로 갈음**(별도 영수증 불필요). 단 **업종별 추가 증빙** 필요:

  | 업종 | 추가 증빙 |
  |------|----------|
  | 편의점·제과점·슈퍼마켓·대형마트 | 거래명세서 |
  | 백화점 푸드코트·호텔·리조트 | 식당명 기재 영수증 |
  | 인터넷 배달(배민 등) | 배달장소 포함 세부내역 |
  | (청정센터 보충) 카페 외 슈퍼·베이커리·삼성코인밴딩(L3매점)·글로벌지식협력단지 | 내역 영수증 |

- ⭐ **카페 판별(보수적)**: **명확한 커피전문점**(스타벅스·테라로사·투썸플레이스·커피빈 등) → 카드전표 갈음(영수증 불요). **업종이 카페인지 애매하면 보수적으로 첨부**. ⚠️ **제과점+카페 겸업**(파리바게트·던킨도너츠·뚜레쥬르 등)은 **제과점 분류 → 거래명세서 첨부**(특히 주의).
- ⚠️ 명확한 카페·일반 식당은 카드전표로 충분(옛 "카페 무조건 첨부"는 부정확). 위 업종 해당 또는 카페 여부 애매 시에만 사용자에게 영수증 요청.
- ⭐ **영수증 파일명 표준 (2026-06-05 정정)**: **`{yymmdd}_{거래처명}.jpg`** (결제일 yymmdd 기준, 예 `260430_파리바게뜨.jpg`).
- ⚠️ **반드시 jpg 변환 필수** — `jpeg`/`png`/`pdf` 등은 행정원 시스템에서 안 받음. 사진 jpg 면 그대로, 다른 확장자면 변환.
- (옵션 = 저장 모드 2 hwp 동봉) 옛 방식: 회의록 hwp 와 **동일 prefix + `_영수증(상호).jpg`**. rename 은 `]` 때문에 python `os.rename`.

## 회의비 규정 (집행 한도·금지) — 매뉴얼
- **1인 5만원 한도**(식대+다과). 메뉴 최저가 5만원 초과 음식점 이용 불가(예 63뷔페).
- **50만원 초과**: 일상감사 + 차상위자 결재(상한 소/본부장), 분할결제 유의.
- **주류·유흥성 불가**(주점·이자카야 등 실주점 포함), **심야 23~06시 불가**, 과제와 직접 관련성 필수(체육대회 답사·행사준비 등 X).
- 휴일·근무지 외(소속 시·군 또는 12km 미만 밖) 사용: **차상위자 전결 사전내부결재** 필요.
- 출장 중 사용: 출장 식비 **공제 확인**(중복 불가, 미반영 시 1식 반납+수입확인서). 출장비와 회의비 계정 다르면 공동계정 사유 기재.

## 사전 내부결재 + 장소·다과 (통합정보 회의비 화면 안내)
정산과제 회의비 식비는 **외부 인원 참석 + 사전 내부결재**가 원칙(계정별 가능 여부는 `project_code.md`). 사전 내부결재:
- **요건**: 전자결재 승인 + 회의 목적·일시·장소·내용·참석자 수(명단) 포함.
- **시점**: '회의 시작' 또는 '식비 실제 사용(카드결제) 시점' 중 **늦은 때까지 완료**(사전 구매·결제는 그 전까지).
- **수정**: 사전결재 내용(목적·일시·장소·참석자)이 바뀌면 → ① **회의록에 변경 반영** 또는 ② 내부결재 사후수정 (사전·사후 결재문서 함께 첨부).
- ⭐ **장소 처리**(회의록 작성 핵심): 장소가 미리 정해짐 → **식당명 기재**. 안 정해짐 → **회의실로 작성 후, '회의실 → 식당명' 변경을 회의록에 기입**해 증빙.
- **다과 구분**: 생수·커피·음료(액체류) = 사전결재 없으면 **영수증 첨부**로 가능. 과자·빵·쿠키·믹스커피(캡슐)·일반차 = **사전결재 필수**.
- 사전 내부결재문서 양식: 통합정보 → 경영정보 → 재무 → 회의비 내부결재 → 작성 → 첨부.

## 회의내용 (10만원 기준)
- **10만원 미만 = 회의내용 생략 가능 / 10만원 이상 = 작성 필수.**
- 무작위 금지 — 회의목적 + 해당 **과제보고서** 테마를 참고해 작성. 항목당 4 하위불릿 정도, **1.·2. 항목 사이 빈 줄 1개**(content 에 `\n` 빈줄).
- ⭐ **중복 금지**: 과거 회의록(아래 폴더)을 작업마다 1회 스캔 → **제목·회의내용 모두 이전 것과 다르게**(같은 제목/내용 재사용 금지).
