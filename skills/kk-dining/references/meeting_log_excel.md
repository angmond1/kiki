# 회의록 엑셀 관리 (hwp 대신, 2026-06-05 신규 표준)

> 회의록 hwp 는 행정원이 보고 fam_0704 회의비 지급신청서를 채우는 용도일 뿐 → **엑셀 1파일에 행 = 건, 9컬럼 = 회의비 작성 필요 항목**으로 관리. Claude 는 항상 엑셀만 조회(여러 건 한눈에 대조 효율).
>
> 저장 모드: **엑셀만 / 엑셀+한글** 사용자 선택. 한글은 옛 보관 선호 사용자 옵션.

## 파일명/위치 표준
- 위치: `C:\kiki\dining\meeting_log\{YYYY.MM}\` (처리월 폴더).
- 파일명: **`{yymmdd}_회의록.xlsx`** (yymmdd = **지급신청 처리일**, 예 `260605_회의록.xlsx`).
- **같은 날 처리하는 회의비 건은 모두 동일 엑셀**에 행 추가 (8건이면 8행).
- 결재상신을 5건씩 분할해도 엑셀은 **처리일 단위 1파일** (상신 단위 ≠ 엑셀 단위).

## 9컬럼 형식 (표본 — `1-2월 회의록.xlsx` 와 동일)
| # | 컬럼 | 내용 | 예시 |
|---|------|------|------|
| 1 | 순번 | 1, 2, ... | 1 |
| 2 | 사용일자 | 회의 일자 + 시간 (또는 카드 결제일자) | `4월 30일 13:00~14:30` |
| 3 | 금액 | 원, 정수 (콤마 포맷) | `323000` |
| 4 | 장소(거래처) | 식당명 = 카드 거래처 | `○○식당` |
| 5 | 처리계정 | 7자리 계정코드 | `26E0001` |
| 6 | 내부참석자 | 성명, 쉼표 구분 | `홍길동` |
| 7 | 외부참석자 | 성명, 쉼표 구분 | `김철수, 이영희, 박민수, ...` |
| 8 | 외부참석자 소속 | 줄바꿈으로 다소속 구분 | `○○대학교` (또는 `A University\nB University`) |
| 9 | 회의목적 | 제목 + 줄바꿈 + 상세 내용 (10만원↑) | `연구 진행상황 논의\n1. ...\n2. ...` |

⚠️ 회의목적 셀에 **목적(제목) + 상세 회의내용**을 함께. 줄바꿈은 `\n` (셀 내 wrap_text).

## 사용일자 표기
- 같은 날 식당+카페 = 1건 → 사용일자에 식당의 식사 시간 기준 (또는 결제 시간 기준).
- 외화결제(해외) = 한국시간/현지시간 함께. 예: `2월 5일\n(미국시간 2월 4일 11시)`.

## 회의시간 융통성 (사용자 확정)
- **회의 종료시간 = 카드승인시간(USETIME)을 참고해 융통성 있게 설정**. 결제는 회의 직후 → 종료 ≤ 결제.
- 예: USETIME 14:38 → 회의 13:00~**14:30** (결제 직전 정각/반정각).
- 30분/시간 단위 반올림 자연스럽게.

## 회의내용 작성 (10만원↑)
- **10만원 미만 = 회의내용 생략 가능 (목적 1줄)** / **10만원↑ = 상세 작성**.
- 무작위 금지 — 회의목적 + 해당 과제보고서 테마 참고. 항목당 4 하위불릿 정도, **1.·2. 항목 사이 빈 줄 1개**.
- ⭐ **중복 금지**: 과거 엑셀(`meeting_log\*\*\*_회의록.xlsx`) 스캔 → 제목·내용 모두 이전과 다르게.

## 파이썬 헬퍼 (`scripts/meeting_log_xlsx.py`)
- `openpyxl` 만 필요. `pyhwpx` 와 달리 한글·COM 불요.
- 9컬럼 양식 자동 생성 + 행 추가 + 회의목적 셀 wrap_text + 금액 `#,##0` 포맷.
- 사용자가 hwp 선호 시 → kk-dining 이 엑셀 행을 읽고 `make_dininglog.py` 로 hwp 도 추가 생성(엑셀이 master).

## 한글파일 동시 저장 (사용자 옵션)
설치 시 묻는 항목 (`kk-dining.config.json`):
```json
"log_format": "xlsx_only" | "xlsx_and_hwp"
```
- `xlsx_only`: 엑셀만 (Claude 기본 권장).
- `xlsx_and_hwp`: 엑셀 + 별지1호 hwp 도 생성 → `C:\kiki\dining\<yymmdd>\` 에 hwp 동봉. **Claude 는 그래도 엑셀만 조회**.

⚠️ **사전결재 < 회의록 우선** — 엑셀에 적힌 내용이 진짜 결과물, 사전결재는 회의 전 계획. fam_0704 사전결재 연동 시 회의내용이 사전결재 템플릿으로 덮어써지면 → 엑셀 원본으로 복원 (자세히는 `fam_0704_automation.md` §9-e).
