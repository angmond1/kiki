# 회의비 비목·사전결재 면제·발의자 (kk-dining)

> 과제번호 구조·분류코드 의미(N/E/I/S/B/F/K/G…)는 **`../_shared/project_codes.md`** 참조. 여기는 **회의비 고유 규칙**만.

## 사전결재 면제 코드
- **분류코드 `I`·`S`·`B`·`F`·부서운영비(부서계정) = 회의비 사전내부결재 면제.**
- 그 외(E·N·M·U·V·Z·G·K 등)는 사전결재 필요 → `fam_0100` 에서 매칭.
- 설치 시: 참여과제(kiki.config.json `projects[].code`) 중 I/S/B/F 자동 선별 + 부서운영비 식별 → "사전결재 면제 맞나요?" 확인. (면제 여부는 분류코드로 자동 판정)
- ⚠️ 옛 `I·S·K` 면제는 부정확 → 현행 `I·S·B·F·부서운영비` (K=자체·석좌=사전결재 필요).

## 회의비 비목 (계정별) — 통합정보 "회의비 집행 예산항목" 안내(2026.06) + wiki 종합
연구비 회의비:
- **기본 `33-523`**(회의비). **K과제(자체·석좌) → `34-448`**.
- **`17-448`** (단 **G계정은 `17-523`·`41-523`**), 그 외 `09-523`·`90-448`.
- 관련: `33-185`(연구실운영비), `33-524`(회의비-세미나개최비).
경상비: `20-440`(매식비)·`28-526`(업무추진비)·`30-512`(교육훈련비)·`32-453`(행사비)·`37-531`(기관업무추진비)·`38-511`(연구개발비) 등.
> 종합: 정산과제(N·M·U·E·V·Z) `33-523` / 수탁·소액(S·I·F·B) `17-448` / **K `34-448`** / **G `17-523`·`41-523`**.
- 비목은 **분류코드로 자동 추정 후 확인** → 회의록 파일명·계정 입력에 사용.
> ⚠️ **사전결재 면제(I·S·B·F·부서운영비)** 와 **비목 17-448(S·I·F·B·K·G)** 은 **별개 기준** — K 는 비목 17-448 이나 사전결재는 필요. B·F 는 양쪽 모두 해당.

## 회의비 식비 사용 가능 여부 (통합정보 회의비 화면 안내)
| 회의 구분 | 식비 |
|----------|------|
| 내부 인원만 + 정부수탁(`N`·`M`·`U`·`G` 정산과제) | **불가** |
| 내부 인원만 + 출연연 기본사업(`E`·`V`·`Z`) | 계정 전 가능 / 계정 후 불가 |
| **외부 인원 참석 회의** | **사전 내부결재 후 사용** |
- 비정산 과제(`I`·`S`·`B`·`A`·`K`·운영비)는 위 표 제외(별도 처리).
- 요지: 정산과제 회의비(식비)는 **외부 인원 참석 + 사전 내부결재**가 원칙. 장소·다과 규칙은 `meeting_form.md`.

## 발의자 vs 계정책임자 (fam_0100 검색 기준)
- **일반 사용자 = 발의자(본인)** 기준 검색(`KORNM`=본인 이름, `PAYNO`=본인 사번 = kiki.config.json `user`).
- 계정책임자(PI)는 별도. skill 기본은 발의자=본인.
- ⚠️ `getListByBonbu` 는 본부 전체 반환(서버필터 미적용) → 응답에서 발의자/과제(acccd)/날짜로 필터 (`fam0100_reference.md`).

## 런타임 분기 (사전결재 ↔ 회의제목)
- 과제가 **면제** 거나 **매칭 사전결재 없음** → 회의목적·시간을 사전결재에서 못 얻음 → **과제보고서 조회**해 회의제목·내용 자동 산출(과거 회의록과 중복 금지). 장소=카드 거래처.
- 사전결재 **매칭 성공** → 목적·장소·시간 그대로 취득. fam_0704 회의록 팝업 `button00_onclick` 으로 연동(`fam_0704_automation.md` §9-d).
- ⚠️ **사전결재 < 회의록 우선** — 연동 시 회의내용 덮어쓰기 → 엑셀 원본 복원(§9-e). 차이(일시/장소/인원/계정)만 변경사유 기재.
