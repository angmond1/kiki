# 메일 분류 정책 — 광고성/predatory 판별 패턴 (보편)

> 이 문서는 **누구에게나 오는** 광고성·predatory 메일의 **판별 패턴**만 담는다.
> 특정 사용자의 개인 발신처 목록·개인 분류 선호는 여기 두지 않는다(각자 `~/.claude/kiki/ki-mail.config.json`).

---

## Tier 1 — 스팸 신고 대상 (광고성/predatory) · 보편

아래 **강한 신호**가 겹치면 광고성 학회/저널 모객(predatory)으로 판단해 스팸 신고를 제안한다.

### 발신 도메인 신호
- **일회성·모객 전용 도메인**: `.info` / `.live` / `.top` 등 TLD에 컨퍼런스명만 박힌 주소, 또는 여러 분야 학회를 같은 패턴으로 대량 운영하는 모객 호스트.
- **대량발송 중계**: `@*.ccsend.com`(Constant Contact) 등 마케팅 메일 중계 경유. (전체 주소 단위 차단이라 무방)
- **정체불명 도메인**: 회사·학회 실체가 불분명한 신생/임의 도메인(`.cloud` 임의 호스트 등).
- **predatory journal 출판사**: 무차별 투고·special issue 권유로 알려진 출판사 계열.

### 본문·제목 신호
- 분야 무관 **무차별 "Invited Speaker / Invited Lecture / Keynote"** 초청.
- "주제·발표 형식 자유" (수신자 연구를 안 보고 보냈다는 신호).
- "special issue 기고 권유" + 마감 임박 압박 + **할인(%)** 미끼.
- 수신자 이름을 제목에 직접 박아 친밀감 위장("<이름> – Lead Global Discussions…").
- 명시적 학회 단체(ACS/RSC/KIChE/KSIEC 등) 부재, 운영사가 직접 모객.

### 기업 마케팅 (광고지만 predatory는 아님)
- 실제 업체의 webinar·신제품·세미나 홍보 뉴스레터. → **스팸 신고보다 "광고 폴더 분류(Tier 2)"가 적절**할 수 있음(사용자 선택).

---

## 정상 메일 (≠ 광고) — 스팸/분류 대상 아님

- **학회 단체 공식 도메인**: `@acs.org`, `@rsc.org`, `@kiche.or.kr`, `@ksiec.or.kr`, `@kchem.org` 등.
- **본인 논문·심사 시스템**: editorialmanager / manuscriptcentral / scholarone / atypon 등에서 오는 **본인 투고·리뷰** 알림.
- **소속 기관 내부**: 본인 회사 도메인 행정·공지.
- **개인 1:1 메일**: 포닥 지원, 동료·교수의 직접 연락. → 스팸 신고 부적절(개인 발신).
- ⚠️ **개인(교수) 발신의 연사 섭외·공동연구 제안**: 답장·후속 대응 필요 → **폴더로 옮기지 말고 받은편지함 유지**.

---

## Tier 2 — 폴더 분류 (선택, 물어보고)

스팸까진 애매한 메일을 폴더로 분류할지 **사용자에게 먼저 묻는다**. 흔한 분류 축(예시일 뿐, 강제 아님):
- **광고**: 기업 마케팅·webinar·할인 홍보.
- **공고**: 연구재단/기관의 공식 공지·접수 안내.
- **학회**: 학회 사무국/단체 공식 발신(개인 교수 직접 메일 제외).
- **시약/거래처**: 시약·기자재 업체의 명세·안내.

> 어떤 축을 쓸지·폴더명·자동분류 여부는 **사용자 선택** → config에 저장.

---

## Tier 3 — 자연어 규칙으로 임의 분류

사용자가 "앞으로 X는 Y 폴더로"라고 하면 조건을 파싱해 규칙 생성:
- **발신 기준**: 도메인(`nature.com`) 또는 주소(`noreply@x.org`) → `fromEmails`.
- **제목 기준**: 키워드("세미나", "Invoice") → `subjectKeywords`.
- 과거 메일 소급(`applyBefore`)은 사용자에게 확인.

### 주의
- **도메인 양면성**: 한 도메인이 정상+광고 섞이면 도메인 일괄 규칙 금지(건별).
- **기관 도메인 전체 규칙 경고**: 예) 연구재단 도메인 전체를 한 폴더로 보내면 중요 공문까지 휩쓸림 → 발신 주소 단위 권장.
