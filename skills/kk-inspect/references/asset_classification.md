# 자산 / 비자산 판정 (보수적)

## ⛔ 판정 철학 — 가장 우선
**소액검수는 대부분 비자산이다.** 보수적으로 판정한다 — 웬만하면 비자산으로 **자동 진행**하고, 자산으로 볼 근거가 뚜렷할 때만 **"이건 자산 같은데 맞나요?"** 라고 사용자에게 확인한다. **비자산은 묻지 않는다.** 애매하면 비자산 쪽으로 기운 뒤, 자산 가능성이 있으면 그때만 확인한다.

## 판정 기준 (wiki 「7-1 자산의 등록」)
**자산(비유동자산)** = 통상 1년 이상 사용 + 아래:
- **기계장치 / 공기구비품**: 취득가 **100만원 이상**
- **PC·노트북 등 정보관리 물품**: **50만원 이상** (저장장치 등 정보 관리 필요 물품)
- **컴퓨터 소프트웨어**: **1천만원 이상** (이 미만 SW는 비자산)
- 시설자산(건물·구축물), 기타(차량운반구·도서)

**비자산(소모품/재료/기타)**:
- 1년 미만 사용 시약·소모성 부품·재료
- 자산성 미달 SW (1천만 미만)
- 전극·셀·글래스·시약·소모품 등 연구 소모재

**내용연수**(자산 등록 시 참고): 기계장치 8년 / 공기구비품 5~8년·노트북 6년 / 컴퓨터SW 3년 / 차량 5년

## 판정 순서 (품목별)
1. **SW/클라우드/라이선스** → 1천만↑ 자산 · 미만 비자산
2. **PC·노트북·정보관리기기** → 50만↑ 자산(확인) · 미만 비자산
3. **일반 물품** → 100만↑ 그리고 1년↑ 비소모성·독립기능 → 자산(확인) · 아니면 비자산
4. **소모성**(시약·전극·부품·재료·글래스류) → 비자산
5. **시작품/시제품** → 별도(수탁사업운영팀) — 사용자 확인
6. **회색지대**(PC부품 합쳐 완성PC·50만↑ 정보기기·한 거래에 자산+비자산 혼재) → 단정 X, 근거 제시하고 사용자 확인
