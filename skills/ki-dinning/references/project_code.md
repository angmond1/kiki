# 과제번호 분류코드 + 사전결재 면제 + 발의자

## 과제번호 구조
`26E0311` = **연도(2자리)** + **분류코드(영문 1자)** + **일련번호(4자리)**.
- 구형식 `2N48010` 등도 존재 → 분류코드 = **숫자 다음 첫 영문자**. 추출 정규식 `/\d+([A-Za-z])/`:
  - `26E0331` → `E` / `26N0110` → `N` / `2N48010` → `N`

## 사전결재 면제 코드
- **분류코드 `I` · `S` · `K` 과제 = 회의비 사전내부결재 불필요(면제).**
- 그 외(E·N 등)는 사전결재 필요 → `fam_0100` 에서 매칭 찾음.
- 설치 시: 참여과제 중 I/S/K 자동 선별 → "이 과제들 사전결재 면제 맞나요?" 확인 → config `projects[].pre_approval` 저장. 면제 과제 없으면 "전 과제 사전결재 필요"로 확인.

## 발의자 vs 계정책임자 (fam_0100 검색 기준)
- **일반 사용자 = 발의자(본인)** 기준으로 사전결재 검색(`KORNM`=본인 이름, `PAYNO`=본인 사번).
- 계정책임자(PI)는 계정책임자 필드로도 가능하나, skill 기본은 **발의자=설치 시 받은 본인 이름**.
- ⚠️ `getListByBonbu` 는 본부 전체를 반환(발의자 서버필터 미적용) → 응답에서 발의자/과제(acccd)/날짜로 거른다 (`fam0100_reference.md`).

## 런타임 분기 (사전결재 ↔ 회의제목)
- 과제가 **면제(I/S/K)** 거나 **매칭 사전결재 없음** → 회의목적(제목)·시간을 사전결재에서 못 얻음 → **과제보고서를 조회해 회의제목·내용을 자동 산출**(과거 회의록과 중복 금지). 장소는 카드 거래처에서.
- 사전결재 **매칭 성공** → 목적(제목)·장소·시간을 그대로 취득.
