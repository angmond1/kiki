## 1. ⭐ 증빙 파일명 규칙 (실패의 핵심 원인)
```
계정번호_항목코드_비목코드_카드승인번호_카드책임자]내용
```
- 언더바(`_`)로 구분, **80자 이내**, **금지 특수문자** `< > : \ / " | ? *` (`]` `(` `)` 공백은 허용)
- **카드승인번호** = 카드영수증 조회(fam_0711)의 `CARDAPPRNO`. **외화도 임의 환산 말고** 조회 원화청구액(`USEAMT`) 그대로.
- **카드책임자** = 카드 명의자 이름(직책 없이, 예 `…_홍길동]…`)
- **복수 증빙** = 동일 파일명 + 끝번호 `(1) (2)`, 각자 확장자
- **세금계산서 건** = 카드결제 아님 → 승인번호 자리 생략 `계정_항목_비목_카드책임자]내용`
- **카드영수증 + 주문내역(거래명세) 둘 다 있으면 → 주문내역만** 업로드(카드전표는 fam_0711 영수증 이관 처리). 단일이면 끝번호 불요.

## 2. 파일 형식 + 자동 전처리
- **`jpg` · `pdf` 만 가능.** `png`·`jpeg`·`xlsx`·`hwp`·`docx`·`hwpx` 등은 불가 → **자동 변환**(`scripts/convert.py`):
  - 이미지 → `jpg`(Pillow), 문서 → `pdf`(한글/Office COM). 변환 시 사용자에게 "X→Y 변환함" 알림.
  - COM 실패 시 → "직접 pdf/jpg 저장 후 재전달" 안내(멈추지 않음).
- 무작위 숫자 파일명(`1780…png`)은 의미있는 이름으로 개명 후 규칙 적용.

## 4. 집행 한도 (붙임2 시트2)
- 의자 100만 / 책상 300만 초과 집행 불가. 연구실 비치용 슬리퍼 3만 초과 불가.
- 이어폰 10만 / 헤드셋·키보드·마우스 20만 / 태블릿 케이스 10만 / 노트북가방 20만 초과 → 용도설명서(연구비는 실행예산 변경요청서).
- 스마트펜슬·태블릿PC·스마트워치 → 용도설명서. 법인폰 관련 비용·개인성 가방은 전부 불가.
- 회의비 식대(다과 포함) 1인 5만원, 50만 초과 시 일상감사+차상위자, 심야(23~6시)·주류 불가.

## 5. 집행 가능 여부 (붙임2 시트3 핵심)

## 7. RPA 운영 규칙
- **RPA 배치**: 매일 10시 / 15시 / 22시 자동 기안 (카드 건만 RPA 자동, 세금계산서·회의비는 행정원 수기).
- **결재선**: RPA 기안 → 연구행정원 결재 → 계정책임자 전결.
- **검수 필수**: 검수 미완료 시 보류(RPA 오류). ⚠️ **물품 100~300만원은 소액검수(mcs_0003) 선행**.
- **성공 시**: 폴더 증빙 휴지통 이동 → 30일 후 삭제. 원본은 본인 보관.
- 결과는 이메일 통보.
