# 과제번호 분류코드 + 회의비 비목 + 사전결재 면제 + 발의자

## 과제번호 구조
`26E0311` = **연도(2자리)** + **분류코드(영문 1자)** + **일련번호(4자리)**.
- 구형식 `2N00009` 등도 존재 → 분류코드 = **숫자 다음 첫 영문자**. 추출 정규식 `/\d+([A-Za-z])/`:
  - `26E0001` → `E` / `26N0002` → `N` / 구형식 `2N00009` → `N`

## 사전결재 면제 코드 (2026-06-05 정정)
- **분류코드 `I` · `S` · `B` · `F` · 부서운영비(부서계정) 과제 = 회의비 사전내부결재 불필요(면제).**
- 그 외(E·N·M·U·V·Z·G·K 등)는 사전결재 필요 → `fam_0100` 에서 매칭 찾음.
- 설치 시: 참여과제 중 I/S/B/F 자동 선별 + 부서운영비 식별 → "이 과제들 사전결재 면제 맞나요?" 확인 → config `projects[].pre_approval=false` 저장. 면제 과제 없으면 "전 과제 사전결재 필요"로 확인.
- ⚠️ 옛 `I·S·K` 면제 기준은 **부정확** → 현행 `I·S·B·F·부서운영비` 로 통일 (K = 자체·석좌 = 사전결재 필요).

## 회의비 비목 (계정별) — 통합정보 지급신청 화면 "회의비 집행 예산항목" 안내(2026.06) + wiki 종합
연구비 회의비:
- **기본 `33-523`** (회의비). **K과제(자체·석좌) → `34-448`**.
- **`17-448`** (단 **G계정은 `17-523`·`41-523`**), 그 외 `09-523`·`90-448`.
- 관련: `33-185`(연구실운영비), `33-524`(회의비-세미나개최비).
경상비: `20-440`(매식비)·`28-526`(업무추진비)·`30-512`(교육훈련비)·`32-453`(행사비)·`37-531`(기관업무추진비)·`38-511`(연구개발비) 등.
> 종합: 정산과제(N·M·U·E·V·Z) `33-523` / 수탁·소액(S·I·F·B) `17-448` / **K `34-448`** / **G `17-523`·`41-523`**. (옛 청정센터 "I 34-448"은 부정확)
- config `projects[].bimok` 에 과제별 비목 저장 → 회의록 파일명·계정 입력. (분류코드로 자동 추정 후 확인)

### 계정 분류코드 의미 (재무팀 매뉴얼)
| 코드 | 구분 | 코드 | 구분 |
|---|---|---|---|
| `N`·`U` | 국가R&D(과기정통부) | `E`·`V`·`Z` | 기관고유(정부 출연금) |
| `M` | 국가R&D(산업부 `MR`·복지부 `ME` 등) | `I` | 민간수탁 |
| `G` | 공공수탁 | `F` | 외국수탁 |
| `K` | 자체·석좌 | `S` | 소액연구 |
| `B` | 민간수탁 종료과제 후속 | `A` | 장비활용 분석시험료 |
> **사전결재 면제(I·S·B·F·부서운영비)** 와 **비목 17-448(S·I·F·B·K·G)** 은 **별개 기준** — 혼동 주의. K 는 비목 17-448 이지만 사전결재는 필요. B·F 는 양쪽 모두 해당.

## 회의비 식비 사용 가능 여부 (통합정보 회의비 화면 안내)
| 회의 구분 | 식비 |
|----------|------|
| 내부 인원만 + 정부수탁(`N`·`M`·`U`·`G` 정산과제) | **불가** |
| 내부 인원만 + 출연연 기본사업(`E`·`V`·`Z`) | 계정 전 가능 / 계정 후 불가 |
| **외부 인원 참석 회의** | **사전 내부결재 후 사용** |
- 비정산 과제(`I`·`S`·`B`·`A`·`K`·운영비)는 위 표에서 제외(별도 처리).
- 요지: 정산과제 회의비(식비)는 **외부 인원 참석 + 사전 내부결재**가 원칙. 사전결재 요건·장소·다과 규칙은 `minutes_form.md`.

## 발의자 vs 계정책임자 (fam_0100 검색 기준)
- **일반 사용자 = 발의자(본인)** 기준으로 사전결재 검색(`KORNM`=본인 이름, `PAYNO`=본인 사번).
- 계정책임자(PI)는 계정책임자 필드로도 가능하나, skill 기본은 **발의자=설치 시 받은 본인 이름**.
- ⚠️ `getListByBonbu` 는 본부 전체를 반환(발의자 서버필터 미적용) → 응답에서 발의자/과제(acccd)/날짜로 거른다 (`fam0100_reference.md`).

## 런타임 분기 (사전결재 ↔ 회의제목)
- 과제가 **면제(I·S·B·F·부서운영비)** 거나 **매칭 사전결재 없음** → 회의목적(제목)·시간을 사전결재에서 못 얻음 → **과제보고서를 조회해 회의제목·내용을 자동 산출**(과거 회의록과 중복 금지). 장소는 카드 거래처에서.
- 사전결재 **매칭 성공** → 목적(제목)·장소·시간을 그대로 취득. fam_0704 회의록 팝업의 `button00_onclick` 으로 사전결재 연동(자세히는 `fam_0704_automation.md` §9-d).
- ⚠️ **사전결재 < 회의록 우선** — 사전결재 연동 시 회의내용 덮어쓰기 → 엑셀/hwp 원본으로 복원 (§9-e). 사전결재 ≠ 회의록(일시/장소/인원/계정) 차이만 변경사유 회의내용 아래 기재.
